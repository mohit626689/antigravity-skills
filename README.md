## 🚀 How to Install & Use in Antigravity / Claude Code

To use any skill in your agent workspace:
1. Clone this repository into your workspace:
   ```bash
   git clone https://github.com/mohit626689/antigravity-skills.git .agents/skills
   ```
2. Your AI agent will automatically detect and register all skills through their respective `SKILL.md` files.
